## Proyectos

- [`simulador-robot-tatuador/`](simulador-robot-tatuador/index.html): banco de pruebas virtual en 3D de un brazo robot que tatúa sobre un antebrazo que se mueve, gira la muñeca, respira y da respingos. La primera versión, en 2D y vista desde arriba, está en [`version-2d.html`](simulador-robot-tatuador/version-2d.html).
